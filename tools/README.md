# Тексты сайта: выгрузка и возврат правок

`../ТЕКСТЫ-САЙТА.md` — вся видимая копия сайта в виде таблицы с ID.
ID вычисляются из порядка элементов в `index.html`, поэтому не хранятся
отдельно: пока разметка не менялась, выгрузка всегда даёт одни и те же ID.

Выгрузить таблицу заново (после правок вёрстки):

    python3 tools/extract.py index.html tools/rows.json && python3 tools/table.py

Вернуть правки из отредактированной таблицы:

    python3 tools/apply.py путь/к/таблице.md --dry   # показать, что изменится
    python3 tools/apply.py путь/к/таблице.md         # применить

Скрипт сам обновляет дубль текста в атрибуте `data-text` у заголовков —
он нужен для эффекта потёртости и должен совпадать с видимым текстом.
Строки, помеченные словом УДАЛИТЬ, скрипт не трогает, а выводит списком:
пустой блок в вёрстке оставлять нельзя, такие места правятся руками.
