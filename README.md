# Harmony — сайт вокальной студии (Ташкент)

Статический одностраничник: чистый HTML / CSS / JS + GSAP ScrollTrigger.
Без сборки, без Node-сервера — заливается на любой хостинг как папка с файлами.

## Запуск локально

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Можно открыть и просто двойным кликом по `index.html`, но Chrome в этом режиме
блокирует загрузку локальных шрифтов (CORS для `file://`) — заголовки покажутся
системным шрифтом. Через `http.server` всё как на проде.

## Деплой

Загрузить содержимое папки в корень хостинга (`public_html`) — или подключить
репозиторий к Vercel / Netlify / Cloudflare Pages: сборка не нужна, output
directory — корень проекта.

После деплоя заменить домен `https://harmonyvocal.uz/` в `index.html`
(canonical, `og:url`, JSON-LD) и в `sitemap.xml`.

## Что нужно вставить перед запуском

Все места помечены в коде комментариями `ЗАМЕНИТЬ` / `ВСТАВИТЬ` и текстом
`[В КВАДРАТНЫХ СКОБКАХ]` прямо на странице.

| Что | Где |
|---|---|
| Фото Мохитобон | `assets/img/teachers/` — квадратный JPG, лицо по центру (как у остальных) |
| Фото с отчётных концертов | `index.html`, блок `.gig__photos` — два кадра |
| Описание Мохитобон | `index.html`, секция `#teachers` — помечено `[ОПИСАНИЕ]` |
| Расписание Камилы и Мохитобон | `index.html` — сейчас «Расписание уточняется» |

Фото педагогов лежат в `assets/img/teachers/` — это вырезанные серединки
круглых картинок из Instagram. Кольца вокруг рисует CSS, поэтому любое новое
фото нужно просто обрезать в квадрат: лицо по центру, вокруг небольшой запас.

Логотип: `assets/img/logo.png` (горизонтальный, в шапке, футере и прелоадере)
и `assets/img/logo-mark.png` (круглый, фавикон и иконка на телефоне).

Отзывы — скриншоты переписок в `assets/img/reviews/`. Вырезаны сами сообщения,
без интерфейса телефона; в карточке кликабельны и открываются в полный размер.
Новый отзыв добавляется копированием блока `.polaroid` — раскладка колонками
сама расставит карточки разной высоты.

Скриншоты приложения — в `assets/img/app/`. Они лежат в слайдере внутри
телефона: свайп работает нативно, стрелки и точки добавляет `main.js`.

Цены, адреса, телефон, соцсети и расписания Далера, Гульшан и Азизы уже
проставлены по данным студии. При изменении цен правьте и JSON-LD в `<head>`
(блок `hasOfferCatalog`).

## Секции сайта

Hero → Направления (современный / экстрим / музыкальная грамотность) →
Формат (только один на один) → Первое занятие → Цены и условия → Педагоги →
Ученики и отчётные концерты → Метод (коротко, мифы в аккордеоне) →
Платформа для тренировок → Вопросы (FAQ) → Запись → Контакты (два филиала).

Порядок секций подчинён продаже: сначала что можно купить и сколько это стоит,
методика — ниже, для тех, кому важны детали.

Тексты в секции «Метод» и FAQ написаны по внутренней методике студии
(анатомия голосового аппарата, ось «безопасно / небезопасно»). При правках
следите, чтобы не вернулись метафоры вроде «пой диафрагмой» и «раскрой
резонаторы» — методика их прямо опровергает.

### Онлайн-запись (Altegio)

Скрипт виджета подключён перед `</body>`:

```html
<script src="https://w1427166.alteg.io/widgetJS" charset="UTF-8"></script>
```

Все кнопки записи помечены классом `ms_booking` — виджет перехватывает клик
и открывает своё окно. Если он вдруг не подхватит кнопки, сработает обычный
якорь и человек попадёт в секцию «Запись», где есть телефон и Telegram.

Хотите форму прямо на странице вместо всплывающего окна — вставьте iframe
из личного кабинета в секцию `#booking` вместо блока `.booking__cta`.

### Карта

Настроена: две вкладки-филиала, карта подгружается лениво, адреса —
Яндекс.Карты по текстовому поиску. Чтобы поставить точные координаты,
замените `data-map` у кнопок `.map__tab` на ссылку вида
`https://yandex.uz/map-widget/v1/?ll=ДОЛГОТА,ШИРОТА&z=17&pt=ДОЛГОТА,ШИРОТА,pm2rdm`.

## Структура

```
index.html
assets/
  css/
    fonts.css        локальные Oswald + Inter (latin + cyrillic)
    base.css         переменные, типографика, кнопки, фоновый декор
    sections.css     стили по секциям
    responsive.css   брейкпоинты 600 / 900 / 1200
  js/
    main.js          меню, модалка записи, слайдер, FAQ, ленивая карта
    animations.js    GSAP + ScrollTrigger
    vendor/          gsap.min.js, ScrollTrigger.min.js (локально)
  fonts/             4 woff2 (~108 КБ на все начертания)
  img/               логотип, микрофон, фото педагогов, экраны приложения, OG-обложка
```

## Как это устроено

- **Мобайл-фёрст.** Базовые стили — мобильные, десктоп добавляется медиазапросами.
  На телефоне микрофон уходит в фон водяным знаком, чтобы первый экран остался
  коротким.
- **Без CDN.** GSAP и шрифты лежат локально: сайт не падает, если CDN недоступен,
  и быстрее грузится на узбекских каналах.
- **Деградация.** Если JS или GSAP не загрузились, весь контент виден и кликабелен —
  анимации только добавляют, ничего не прячут навсегда.
- **`prefers-reduced-motion`** отключает анимации целиком.
- **Ленивая загрузка** у всех изображений ниже первого экрана и у карты.
